# MyWatchlist C.U.R.Operation 🎬

A fully client-side web application that allows users to **Create**, **Update**, and **Remove** items from their personal movie/TV show watchlist — all built using just **HTML**, **CSS**, and **JavaScript**.

## 🔗 Live Demo

👉 [Visit the App](https://akw.static.domains/)

## ✨ Features

- ✅ Add new movies or shows to your watchlist
- ✏️ Edit existing entries (title, description, etc.)
- ❌ Remove entries from the list
- 💾 Data stored locally in the browser using `localStorage`
- 📱 Responsive and clean UI

## 🛠 Tech Stack

- **HTML** – Structure of the application
- **CSS** – Styling and layout
- **JavaScript** – Logic for all CRUD operations and local data management
